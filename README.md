# Object-Oriented Programming (OOP) - TPs

This repository contains my practical works (TPs) and exercises for the **Object-Oriented Programming** course, implemented primarily in **Java**.

##  Repository Structure

Each folder or exercise corresponds to a specific practical assignment, covering core OOP concepts:

* **Basic Java & Syntax:** Variables, loops, methods, and user input via `Scanner`.
* **Classes & Objects:** Constructors, attributes, methods, and encapsulation.
* **Arrays & Matrices:** 2D arrays, manipulation, and custom logic (e.g., matrix processing based on row indices).
* **Control Structures:** Conditional statements (`if-else`, logical operators like `&&`) and validation loops (`do-while`).

---

##  Examples of Included Exercises

* **Matrix Processing:** Programs to initialize matrices dynamically and populate rows based on even/odd conditions.
* **Divisibility Checkers:** Logic-based programs utilizing modulo operations (`%`) and logical operators (`&&`).
* **Input Validation Loops:** Robust console input loops ensuring valid user ranges using `do-while`.

---

##  Requirements & Tools

* **Language:** Java (JDK 8 or higher)
* **IDE:** Visual Studio Code / IntelliJ IDEA / Eclipse
